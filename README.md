# Zevgram

Zevgram — локальная мини-соцсеть на русском языке. Она запускается на компьютере без платных сервисов, сторонних библиотек и обязательного подключения к интернету.

## Что уже работает

- Регистрация и вход по логину и паролю
- Публикации, лайки и комментарии
- Профили с аватарками, редактируемым ником `@username` и описанием «О себе»
- Поиск и добавление пользователей в друзья
- Личные сообщения между профилями
- Создание сообществ и вступление в них
- Закладки для публикаций
- Сохранение аккаунтов и контента в локальных JSON-файлах

## Запуск в Windows

1. Установи Node.js, если его ещё нет.
2. Дважды щёлкни `start-zevgram.bat`.
3. Оставь открытым окно запуска. Сайт откроется по адресу `http://127.0.0.1:4173`.

Сервер слушает только локальный компьютер. Это приложение не публикуется в интернете автоматически. Для публичного сайта понадобится отдельный хостинг и настройка безопасности.

## Данные и безопасность

Данные аккаунтов и сообщества создаются рядом с приложением:

- `zevgram-users.json`
- `zevgram-posts.json`
- `zevgram-social.json`

Эти файлы исключены из Git. Не загружай их в публичный репозиторий: они содержат пользовательские данные. Пароли хранятся в виде производного хеша, а не открытым текстом.

## Зависимости

Используются только встроенные модули Node.js. Установка пакетов не требуется.

## Интернет-версия для Telegram-бота

Проект также содержит общедоступную версию для Cloudflare Workers и общую базу D1. Публикации, профили, друзья, сообщества и личные сообщения хранятся в интернете и доступны участникам из разных устройств. После размещения скопируй адрес `*.workers.dev` из окна публикации и вставь его в URL-кнопку Telegram-бота.

Для размещения нужен бесплатный аккаунт Cloudflare. Платные функции не подключаются; у бесплатного тарифа есть дневные лимиты на операции с базой. Если лимит будет превышен, запросы к базе будут временно недоступны до следующего сброса. [Лимиты D1](https://developers.cloudflare.com/d1/platform/limits/).

1. Установи Node.js (LTS), если он ещё не установлен.
2. Запусти `deploy-cloudflare.bat` и подтверди вход в Cloudflare в открывшемся браузере.
3. После завершения скопируй показанный адрес сайта и вставь его в кнопку своего бота.

Новая интернет-версия использует отдельную базу: аккаунт, созданный в локальной версии, автоматически туда не переносится. Зарегистрируй профиль на сайте после публикации.
